## 历史开发验收

原开发工作目录在 v0.5.1 有 614 项本机单元测试通过。BGB 对两种模式的五关介绍及进入关卡做过采样；场景 5 滚动停顿区间，旧版顶部残留 20–24 个文字像素，新版为 0，独立回退副本恢复旧版表现。

以上是历史本机验收，不是本仓库 GitHub Actions 的测试数量。本仓库只运行自身公开测试，不在 CI 下载、保管或上传 ROM；当前独立构建的哈希复现记录见 `docs/VERIFICATION.txt`。

## 已分析并放弃的改动

场景 5 介绍文字下移 2px（页面 y36-47 → y38-49）经完整排查后**判定不可行并已回退**，
原因是在「卷轴轨迹不变」的约束下，文字底边 49 必然在 SCY=48 的停顿期露出顶部 2 行；
VBlank 代码补丁会让 credits 滚动产生 1px 闪烁（实测阈值 8 个周期），改卷轴则会
让页面底部的山尖提前露出。完整实测数据见
[场景 5 文字位置分析](STAGE5_CAPTION_2PX.md)。
